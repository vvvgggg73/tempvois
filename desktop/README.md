# Сборка NOCTURNE для Windows

Установщик создается на Windows 10/11 x64. Нужны .NET 10 SDK и Inno Setup 6.

1. Установите Inno Setup 6 с https://jrsoftware.org/isdl.php.
2. Откройте PowerShell в корне репозитория.
3. Запустите `desktop\build.ps1`.

Готовый `NOCTURNE-Setup-x64.exe` появится в `dist`. Установщик распаковывает приложение и `index.html` в папку программы, создает ярлыки и сжимает установочные файлы алгоритмом LZMA2. Приложение публикуется вместе с .NET, поэтому отдельно устанавливать .NET Runtime не нужно.

Для отображения приложения требуется Microsoft Edge WebView2 Runtime. Если его нет, NOCTURNE предложит открыть страницу загрузки Microsoft.

Сжатие без потерь ограничено содержимым файлов. Для HTML сжатие обычно значительно; файлы среды выполнения .NET занимают основную часть размера установщика.
